#### 2. 小时表达（12条规则）

| 模式 | 示例 | 含义 | Grain | 状态 |
|------|------|------|-------|------|
| X点 (中文) | 三点 | 3:00 | Hour | ✅ |
| X點 (繁体) | 五點 | 5:00 | Hour | ✅ |
| X点 (数字) | 3点, 15点 | 3:00, 15:00 | Hour | ✅ |
| X点Y分 (中文) | 三点十五分 | 3:15 | Minute | ✅ |
| X點Y分 (繁体) | 七點三十分 | 7:30 | Minute | ✅ |
| X点Y分 (数字) | 15点30分 | 15:30 | Minute | ✅ |
| X点零Y分 | 九点零五分 | 9:05 | Minute | ✅ |
| X点差Y分 | 三点差五分 | 2:55 | Minute | ✅ |
| X点一刻 | 三点一刻 | 3:15 | Minute | ✅ |
| X点半 | 三点半 | 3:30 | Minute | ✅ |

**中文数字支持**:
- 零 (0), 一 (1), 二/两/兩 (2), 三 (3), 四 (4), 五 (5)
- 六 (6), 七 (7), 八 (8), 九 (9), 十 (10)
- 十一 (11), 十二 (12), ..., 二十三 (23)

**示例**:
```
三点         → 3:00
五點         → 5:00
3点          → 3:00
三点十五分   → 3:15
七點三十分   → 7:30
15点30分     → 15:30
九点零五分   → 9:05
三点差五分   → 2:55 (5 minutes before 3)
三点一刻     → 3:15 (quarter past 3)
三点半       → 3:30 (half past 3)
```

#### 3. 5分钟单位标记 - 粤语（4条规则）

| 模式 | 示例 | 计算 | 含义 | 状态 |
|------|------|------|------|------|
| X点踏Y | 三点踏五 | 3 + 5×5 | 3:25 | ✅ |
| X点搭Y | 五点搭七 | 5 + 7×5 | 5:35 | ✅ |
| X点Y個字 | 三点五個字 | 3 + 5×5 | 3:25 | ✅ |
| 范围 | 1-11個字 | Y×5分钟 | 5-55分 | ✅ |

**粤语特色**:
- "踏/搭" (tap/dap) - 粤语口语表达
- "個字" (go zi) - 字钟，每个"字"代表5分钟
- 有效范围: 1-11 (对应 5-55分钟)

**示例**:
```
三点踏五     → 3:25 (3 + 5×5)
五点搭七     → 5:35 (5 + 7×5)
三点五個字   → 3:25 (5×5分钟)
十点一個字   → 10:05 (1×5分钟)
十点十一個字 → 10:55 (11×5分钟)
```

#### 4. 特殊分钟表达（3条规则）

| 表达 | 示例 | 含义 | 状态 |
|------|------|------|------|
| 一刻 | 一刻/一刻钟 | 15 minutes | ✅ |
| 三刻 | 三刻/三刻钟 | 45 minutes | ✅ |
| 半小时 | 半小时/半個小時 | 30 minutes | ✅ |

### 技术实现

**新增函数**:
1. `parse_chinese_number()` - 中文数字解析器
   - 支持: 零-九, 十-九十九

3. `add_hour_minute_rules()` - 时刻规则生成器

## 🔍 技术亮点

### 1. 中文数字解析


**支持**:

- 十系列: 十, 十一-十九
