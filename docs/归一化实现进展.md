## 什么是归一化？

将不同的输入表达统一转换为标准的Value结构：

| 输入表达 | 归一化输出 | 维度 |
|---------|-----------|------|
| "twenty three", "23", "二十三" | Value::Integer(23) | Numeral |
| "0.5", "half", "一半" | Value::Float(0.5) | Numeral |
| "5 minutes", "5分钟", "five mins" | Duration{value:5, unit:Minute} | Duration |
| "3 kilometers", "3km", "三公里" | Distance{value:3, unit:Kilometer} | Distance |
| "3pm", "15:00", "下午3点" | Time{...} | Time |

## 关键技术问题

### ✅ 问题1: Regex捕获组导致panic（已解决）

**现象**:
```
NoCapture("No capture for regexp (?i)(a )?(pair|couple)s?( of)?...")
```

**根本原因**:
- Haskell regex: `(a )?(pair|couple)s?( of)?` - 有3个捕获组
- 代码访问: `text_match.group(2)` - rustling-core会panic

**影响范围**: 所有自动生成的复杂regex规则（~20%规则）

**✅ 已实施的解决方案**:

在`tools/migration/extract_rules.py`中实现`sanitize_regex()`函数：
```python
@staticmethod
def sanitize_regex(pattern: str) -> str:
    """Convert capturing groups to non-capturing groups"""
    result = []
    i = 0
    while i < len(pattern):
        if pattern[i:i+2] == r'\(':
            result.append(r'\(')
            i += 2
        elif pattern[i] == '(' and i+1 < len(pattern) and pattern[i+1] != '?':
            result.append('(?:')  # 转换为非捕获组
            i += 1
        else:
            result.append(pattern[i])
            i += 1
    return ''.join(result)
```

**结果**:
- ✅ 所有regex规则使用`group(0)`或sanitized pattern
- ✅ 不再有NoCapture panic
- ✅ 模板已更新，默认使用安全的regex模式

### ✅ 问题3: Composite规则实现（已解决）

**关键突破**: ValueKind枚举

**问题**: rule_2规则不触发，"twenty three"只产生[20, 3]，没有23

**根本原因**: StashIndexable::Index使用了Value本身
```rust
// ❌ 错误实现
impl StashIndexable for Value {
    type Index = Value;  // 太具体，每个值都是不同的Index
}
```

**✅ 解决方案**: 创建ValueKind枚举
```rust
#[derive(Debug, Copy, Clone, PartialEq, Eq, Hash)]
pub enum ValueKind {
    Integer, Float, Duration, Time
}

impl StashIndexable for Value {
    type Index = ValueKind;  // 轻量级类型标记
    fn index(&self) -> Self::Index { self.kind() }
}
```

**简化API**: 使用dim!宏
```rust
// 简化前
FilterNodePattern::<Value>::filter(vec![
    Box::new(|v: &Value| matches!(v, Value::Integer(n) if *n >= 20))
])

// 简化后（使用dim!宏）
dim!(Value, vec![Box::new(|v: &Value| {
    matches!(v, Value::Integer(n) if *n >= 20)
})])
```

**结果**: 所有composite规则正常工作
- ✅ CompositeTens: "twenty three" → 23
- ✅ Multiply: "three hundred" → 300
- ✅ Sum: "one thousand two hundred" → 1200
- ✅ SumAnd: "one hundred and twenty three" → 123

详见：`docs/ValueKind-关键突破.md`

**挑战**:
- API冗长（FilterNodePattern + Box::new + 闭包）
- 难以自动化生成
- 需要理解Haskell语义（Predicate, oneOf等）

**简化方案**: 创建辅助宏
```rust
// 理想API:
b.composite_2(
    "en:composite_tens",
    value_filter!(Integer(20..=90, step=10)),
    value_filter!(Integer(1..=9)),
    |tens, units| Ok(Value::Integer(tens + units))
);
```
