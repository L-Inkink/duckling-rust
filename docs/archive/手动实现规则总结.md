## ✅ 已实现的规则

### 1. Dozen Rule (简单常量规则)

**类型**: 简单 Regex → 常量值

**Haskell 原始代码**:
```haskell
ruleDozen :: Rule
ruleDozen = Rule
  { name = "a dozen of"
  , pattern = [ regex "(a )?dozens?( of)?" ]
  , prod = \_ -> integer 12 >>= withMultipliable >>= notOkForAnyTime
  }
```

**Rust 实现**:
```rust
b.rule_1_terminal(
    "en:dozen",
    b.reg(r"(?i)(a\s+)?dozens?(\s+of)?").unwrap(),
    |_| {
        // Always returns 12
        Ok(Value::Integer(12))
    }
);
```

**模式特征**:
- ✅ 简单regex匹配
- ✅ 返回固定常量值
- ✅ 不依赖任何字典或其他规则
- ✅ 生产函数忽略输入（`|_|`）

**可自动化**: ✅ **100%** - 如果 JSON 中包含固定值

### 2. Tens Rule (字典查找规则)

**类型**: Regex → 字典查找

**Haskell 原始代码**:
```haskell
ruleTens :: Rule
ruleTens = Rule
  { name = "integer (20..90)"
  , pattern = [ regex "(twenty|thirty|fou?rty|fifty|sixty|seventy|eighty|ninety)" ]
  , prod = \tokens -> case tokens of
      (Token RegexMatch (GroupMatch (match:_)):_) ->
        HashMap.lookup (Text.toLower match) tensMap >>= integer
      _ -> Nothing
  }
```

**Rust 实现**:
```rust
{
    let dict = &*TENS_DICTIONARY;
    b.rule_1_terminal(
        "en:tens",
        b.reg(r"(?i)twenty|thirty|fou?rty|fifty|sixty|seventy|eighty|ninety").unwrap(),
        move |text_match| {
            let text = text_match.group(0).to_lowercase();
            dict.get(text.as_str())
                .map(|&value| Value::Integer(value))
                .ok_or_else(|| rustling_error!("Tens dictionary lookup failed for: {}", text))
        }
    );
}
```

**模式特征**:
- ✅ Regex 匹配文本
- ✅ 从匹配的文本中提取 group(0)
- ✅ 转换为小写
- ✅ 在字典中查找
- ✅ 返回字典中的值

**可自动化**: ✅ **100%** - 如果 JSON 中包含 dictionary_ref

## 🚫 无法自动化的规则类型

### 1. 组合规则 (CompositeTens)

**原因**: 需要匹配已解析的 token，需要使用 `rule_2` 或 `rule_3`

```haskell
pattern =
  [ oneOf [20,30..90]        -- 匹配已解析的数字
  , regex "[\\s\\-]+"
  , Predicate $ numberBetween 1 10
  ]
```

**Rust 需要**:
- FilterNodePattern 来匹配特定值范围的数字
- rule_3 来组合三个模式
- 访问前面解析的数字值

**手动实现复杂度**: 高 ⚠️

### 2. 谓词规则 (Predicate)

**原因**: 需要实现自定义谓词函数

```haskell
Predicate $ numberBetween 1 10
Predicate $ not . hasGrain
```

**需要**: 在 Rust 中实现对应的谓词函数

### 3. 多步骤生产逻辑

**原因**: 复杂的值计算

```haskell
prod = \tokens -> case tokens of
  (...:...:...:_) -> do
    hundreds <- HashMap.lookup x1 map1
    tens <- HashMap.lookup x2 map2
    units <- HashMap.lookup x3 map3
    integer (hundreds * 100 + tens + units)
```

**需要**: 手动翻译 Haskell 的计算逻辑
