## 本轮实现的规则

### 1. Decimals（小数解析）

**原始Haskell规则**:
```haskell
ruleDecimals :: Rule
ruleDecimals = Rule
  { name = "decimal number"
  , pattern = [ regex "(\\d*\\.\\d+)" ]
  , prod = \tokens -> case tokens of
      (Token RegexMatch (GroupMatch (match:_)):_) -> parseDecimal True match
      _ -> Nothing
  }
```

**Rust实现**:
```rust
b.rule_1_terminal(
    "en:decimals",
    b.reg(r#"(?i)(\d*\.\d+)"#).unwrap(),
    |text_match| {
        let text = text_match.group(1);
        text.parse::<f64>()
            .map(|f| Value::Float(f))
            .map_err(|_| rustling_error!("Failed to parse decimal: {}", text))
    }
);
```

**关键发现**:
- 需要添加 `Value::Float(f64)` 变体到核心Value枚举
- 需要为Value实现自定义的Eq和Hash（因为f64不实现这些trait）
- 简单的字符串解析模式：`text.parse::<f64>()`

### 2. Commas（逗号分隔数字）

**原始Haskell规则**:
```haskell
ruleCommas :: Rule
ruleCommas = Rule
  { name = "comma-separated numbers"
  , pattern = [ regex "(\\d+(,\\d\\d\\d)+(\\.\\d+)?)" ]
  , prod = \tokens -> case tokens of
      (Token RegexMatch (GroupMatch (match:_)):_) ->
        parseDouble (Text.replace "," Text.empty match) >>= double
      _ -> Nothing
  }
```

**Rust实现**:
```rust
b.rule_1_terminal(
    "en:commas",
    b.reg(r#"(?i)\d+(?:,\d\d\d)+(?:\.\d+)?"#).unwrap(),
    |text_match| {
        let text = text_match.group(0).replace(",", "");
        text.parse::<f64>()
            .map(|f| {
                if f.fract() == 0.0 {
                    Value::Integer(f as i64)
                } else {
                    Value::Float(f)
                }
            })
            .map_err(|_| rustling_error!("Failed to parse comma-separated number: {}", text))
    }
);
```

**关键发现**:
- 字符串替换 + 解析模式：`text.replace(",", "").parse::<f64>()`
- 根据小数部分选择Integer或Float
- 使用非捕获组 `(?:...)` 避免rustling-core的捕获组错误

## 提取的自动化模式

### Pattern 3: 字符串解析模式（String Parse Pattern）

**识别特征**（来自JSON）:
```json
{
  "production": {
    "value_extractor": "custom",
    "custom_logic": "NEEDS_MANUAL_REVIEW: prod = \\case\n      (Token RegexMatch (GroupMatch (match:_)):_) -> parseDecimal True match"
  }
}
```

**Haskell识别规则**:
- `prod` 中调用 `parseDecimal`, `parseDouble`, `parseInt` 等函数
- 模式：`(Token RegexMatch (GroupMatch (match:_)):_) -> parseXXX match`

**自动化策略**:
```json
{
  "rule_type": "regex",
  "pattern": {
    "type": "regex",
    "value": "(\d*\.\d+)"
  },
  "production": {
    "value_extractor": "parse_string",
    "parse_type": "float",  // or "integer", "double"
    "capture_group": 1
  }
}
```

**代码生成模板**:
```rust
b.rule_1_terminal(
    "{{ locale }}:{{ rule.name }}",
    b.reg(r#"(?i){{ rule.pattern.value }}"#).unwrap(),
    |text_match| {
        let text = text_match.group({{ rule.production.capture_group }});
        text.parse::<{{ rust_type }}>()
            .map(|v| Value::{{ value_variant }}(v))
            .map_err(|_| rustling_error!("Failed to parse: {}", text))
    }
);
```

**自动化程度**: 90%（需要区分返回Integer还是Float）

### Pattern 4: 文本替换 + 解析模式（Replace & Parse Pattern）

**识别特征**（来自JSON）:
```json
{
  "production": {
    "value_extractor": "custom",
    "custom_logic": "NEEDS_MANUAL_REVIEW: prod = \\case\n      (Token RegexMatch (GroupMatch (match:_)):_) ->\n        parseDouble (Text.replace \",\" Text.empty match)"
  }
}
```

**Haskell识别规则**:
- `prod` 中调用 `Text.replace` 或 `Text.filter`
- 模式：`parseXXX (Text.replace "pattern" "" match)`

**自动化策略**:
```json
{
  "rule_type": "regex",
  "pattern": {
    "type": "regex",
    "value": "\d+(,\d\d\d)+(\.\d+)?"
  },
  "production": {
    "value_extractor": "replace_and_parse",
    "replace_pattern": ",",
    "replace_with": "",
    "parse_type": "float",
    "capture_group": 0
  }
}
```

**代码生成模板**:
```rust
b.rule_1_terminal(
    "{{ locale }}:{{ rule.name }}",
    b.reg(r#"(?i){{ rule.pattern.value }}"#).unwrap(),
    |text_match| {
        let text = text_match.group({{ rule.production.capture_group }})
            .replace("{{ rule.production.replace_pattern }}", "{{ rule.production.replace_with }}");
        text.parse::<{{ rust_type }}>()
            .map(|v| {
                {% if rule.production.adaptive_type %}
                if v.fract() == 0.0 {
                    Value::Integer(v as i64)
                } else {
                    Value::Float(v)
                }
                {% else %}
                Value::{{ value_variant }}(v)
                {% endif %}
            })
            .map_err(|_| rustling_error!("Failed to parse: {}", text))
    }
);
```

**自动化程度**: 85%（需要正则识别`Text.replace`调用和参数）

## 新发现的技术问题与解决方案

### 问题1: Value枚举缺少Float变体

**问题**: 原始rustling只有`Value::Integer`，不支持浮点数

**解决方案**:
1. 添加 `Float(f64)` 变体到 `src/values/mod.rs`
2. 移除自动派生的 `Eq` 和 `Hash`
3. 手动实现这两个trait，使用 `f64.to_bits()` 来处理浮点数

```rust
#[derive(Debug, Clone, PartialEq, Serialize, Deserialize)]
pub enum Value {
    Integer(i64),
    Float(f64),
    Duration(DurationValue),
    Time(TimeValue),
}

impl Eq for Value {}

impl Hash for Value {
    fn hash<H: Hasher>(&self, state: &mut H) {
        match self {
            Value::Float(f) => {
                1u8.hash(state);
                f.to_bits().hash(state);
            }
            // ... 其他变体
        }
    }
}
```

**影响范围**: 核心模块，需要在Phase 1早期完成

---

### 问题2: Regex捕获组与rustling-core的限制

**问题**: rustling-core在访问不存在的捕获组时会panic

**解决方案**:
1. 使用非捕获组 `(?:...)` 代替普通捕获组 `(...)`
2. 访问 `group(0)` 获取完整匹配（总是安全的）
3. 只在需要提取子串时使用捕获组

**反面案例**:
```rust
b.reg(r#"(\d+(,\d\d\d)+(\.\d+)?)"#)  // ❌ 3个捕获组，访问group(1)会出错
```

**正面案例**:
```rust
b.reg(r#"\d+(?:,\d\d\d)+(?:\.\d+)?"#)  // ✅ 0个捕获组，只用group(0)
```
